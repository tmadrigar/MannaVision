## 📖 Sobre o Projeto

MannaVision é uma tela de pintura digital que dispensa mouse ou teclado. Utilizando a câmera do seu dispositivo, a aplicação rastreia os movimentos das suas mãos através da inteligência artificial do **MediaPipe Hands**, permitindo uma experiência de desenho natural e intuitiva.

O projeto foi desenvolvido como uma exploração das capacidades de interação humano-computador, transformando um simples gesto de pinça em uma poderosa ferramenta de criação artística.

## 🚀 Funcionalidades Principais

-   ✍️ **Desenho por Gestos**: Ative o pincel simplesmente unindo o polegar e o indicador.
-   ✌️ **Suporte para Duas Mãos**: Detecta e rastreia até duas mãos simultaneamente, permitindo desenhar com ambas.
-   🎨 **5 Estilos de Pincel Criativos**: Escolha entre **Sólido**, **Brilhante**, **Spray**, **Tracejado** e o dinâmico **Psicodélico**.
-   🎨 **Paleta de Cores e Ferramentas**: Controle total com seletor de cores, ajuste de espessura e modo borracha.
-   🎨 **Temas de Interface**: Personalize a aparência da aplicação com 4 temas de cores (Roxo, Azul, Verde e Rosa).
-   🖼️ **Salvar Criações**:
    -   **Salvar Desenho**: Exporte apenas a arte em `.png` com fundo transparente.
    -   **Salvar Recordação**: Capture um "print" da tela, mesclando sua webcam, o desenho e a logo do MannaVision.
-   📋 **Modo Lousa**: Alterne para um fundo branco para uma experiência de desenho mais tradicional.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído com as mais modernas tecnologias de frontend para garantir performance e uma ótima experiência de desenvolvimento.

| Tecnologia | Descrição |
| :--- | :--- |
| **React** | Biblioteca principal para a construção da interface do usuário. |
| **TypeScript** | Superset do JavaScript que adiciona tipagem estática. |
| **MediaPipe Hands** | Solução de IA do Google para rastreamento de mãos em tempo real. |
| **Tailwind CSS** | Framework CSS utility-first para estilização rápida e moderna. |
| **Vite** | Ferramenta de build de nova geração para desenvolvimento web. |
| **Lucide React** | Biblioteca de ícones SVG, leve e personalizável. |

## ⚙️ Instalação e Execução Local

Para executar este projeto em sua máquina, siga os passos abaixo.

### Pré-requisitos
-   [Node.js](https://nodejs.org/) (versão 16 ou superior)
-   [Git](https://git-scm.com/)

### Passos

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/tmadrigar/MannaVision.git](https://github.com/tmadrigar/MannaVision.git)
    ```

2.  **Navegue até o diretório do projeto:**
    ```bash
    cd MannaVision
    ```
    
3.  **Entre na pasta da aplicação:**
    ```bash
    cd handraw-pipe
    ```

4.  **Instale as dependências:**
    ```bash
    npm install
    ```

5.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    ```

6.  Abra seu navegador e acesse `http://localhost:5173` (ou a porta indicada no terminal).
